# Nova Digital Market

Build a polished, premium Arabic-first (Egyptian Arabic friendly) digital products marketplace storefront. Use a bold luxury dark theme with black backgrounds, violet/purple neon accents, subtle gradients, crisp typography, responsive mobile-first layout, and RTL support for Arabic while allowing English product names. Brand name: choose a strong memorable premium English name, e.g. NOVA MARKET. Create a complete first-draft frontend with: homepage hero, category navigation, search and filters, featured/bestseller product cards, product detail modal/page, cart drawer, checkout flow clearly marked DEMO ONLY (no real payment processing), order confirmation demo, FAQ and footer. Add broad legitimate digital-product categories such as gift cards, game top-ups, software licenses, subscriptions, and digital tools. Use sample placeholder products/prices clearly treated as editable demo catalog; do not copy dark.shopping branding, text, or assets. Add an admin dashboard mockup with product CRUD UI, stock/status, orders, sales summary, and editable pricing, using local/demo state if backend isn't configured. Include clear hooks/placeholders for future payment gateway and automatic fulfillment integrations, but do not pretend those integrations work. Ensure polished empty/loading/error states, accessible contrast, responsive design, and realistic Egyptian market UX. Avoid any products implying stolen accounts, hacked credentials, or unauthorized access. Deliver a visually impressive usable prototype.
